3. `docs/chapter24_multimodal_frontier/embodied-intelligence/model-based-rl/index.md` — "Chapters 8 to 10 of this book discussed DPO, PPO, GRPO, and Agentic RL, but rarely emphasized MBRL separately." 4. `docs/chapter24_multimodal_frontier/embodied-intelligence/model-based-rl/index.md` (Q5, "Model-Based" code block) — `target = torch.cat([next_state - state, reward, done], dim=-1)` then `mu, logvar = world_model(state, action); model_loss = gaussian_nll(mu, logvar, target)`. Two concrete defects: (i) `reward` and `done` are 0-dim tensors, and `torch.cat` refuses them — verified in this repo's venv: `RuntimeError: zero-dimensional tensor (at position 1) cannot be concatenated`; (ii) even with `unsqueeze(-1)` the target has `state_dim + 2` entries, while the model defined earlier on the same page is `out_dim = state_dim + 1  # delta_state + reward`, so `gaussian_nll` would broadcast-fail. The same page's minimal-practice block does it correctly (`torch.cat([next_state - state, reward.unsqueeze(-1)], dim=-1)`), and the imagined-rollout loop below calls `split_prediction(pred)` expecting a termination output the model does not produce. — Suggested fix: use `target = torch.cat([next_state - state, reward.unsqueeze(-1)], dim=-1)` and drop `done` from the target (or extend the model with a termination head, `out_dim = state_dim + 2`, and adjust `split_prediction` accordingly).

5. `docs/chapter24_multimodal_frontier/embodied-intelligence/index.md` — "In Chapter 8 we learned PPO's deterministic policy output -- given a state, the network outputs an action vector." PPO is not a deterministic-policy method: Chapter 8's PPO maximizes a clipped surrogate over a _stochastic_ policy, and the same page says so a few sections earlier — "We typically assume the policy follows a Multivariate Gaussian Distribution ... the network outputs a $k$-dimensional mean vector ... and a $k$-dimensional standard deviation vector (determining exploration randomness)". The deterministic policies in this book are DDPG/TD3 (Chapter 9). The sentence also inverts the stated motivation for diffusion policies: a Gaussian PPO policy is multimodal-hostile precisely _because_ it is a unimodal Gaussian, not because it is deterministic. — Suggested fix: "In Chapter 8 we learned PPO's clipped policy-gradient update -- given a state, the network outputs a distribution over actions (a Gaussian mean and standard deviation in continuous control)."

6. `docs/chapter24_multimodal_frontier/video-generation-modern.md` (§24.5.3, VADER) — "gradients are kept only for the last $K$ steps, and earlier steps apply stop-grad, that is, for $K<T$ the network predictions at $t>K$ are cut out of the computation graph." The index is inverted: the sentence says the _early_ steps are stop-gradiented, but "$t>K$" cuts the _late_ predictions. With $T=50$ and $K=10$, "$t>K$" would remove the gradients of steps 11…50, i.e. exactly the last $K$ steps whose gradients are supposed to be kept, leaving nothing to backpropagate into. — Suggested fix: "the network predictions at $t\le T-K$ are cut out of the computation graph."

No such triple exists in §24.1, which gives only the symbolic $R_{\mathrm{total}}=w_cR_{\mathrm{content}}+w_pR_{\mathrm{prosody}}+w_lR_{\mathrm{latency}}$ and then argues about which layer to emphasize; §24.2 uses a different triple, `weights=(0.7,0.2,0.1)` for content/prosody/**format** (not latency); the only 0.8 in the chapter is the MGRD composite reward $0.8\cdot\mathbb 1[a=a^*]+0.2\cdot\mathbb 1[\text{reasoning}]$, which is content-vs-format, not content/prosody/latency. ## Verdict

The core edits are good and I could confirm them independently: the two SFT/mid-training losses really were written as positive log-likelihoods presented as losses to minimize, the RLHF objective really was labelled $\mathcal{L}$ while being maximized, the "four thousand forward passes" claim really was wrong for a jointly-attended DiT (one forward pass per denoising step over all 80 frames; $50\times80=4{,}000$ counts frame-level latent updates), the LongCat/Seedance editorial aside really was meta-commentary that should go, and the stale chapter numbers in both "Connections" tables (5-6 → 6-7, 7 → 8, 6 → 7, 11 → 23, 8 → 13) were all wrong and are now right. I re-derived every exercise solution: the GRPO advantages $(-\!1.2247, 0, +1.2247)$ from $\text{std}=\sqrt{2/3}\approx0.8165$, the token counts $75\times8=600$ and $6{,}000$, the frame counts $80$/$120$, the video totals $0.5875$/$0.60$, the PD torque $16$, and the baseline-gradient proof (which is correct); I also re-ran `snippets/minimal_mbrl_point_mass.py` and reproduced `one_step_model_mse=0.013716`, `random_policy_return=-2246.07`, `mbrl_mpc_return=-18.76` exactly as printed. The problems are integration and consistency rather than derivation: the new `review.md` is not in the sidebar and is numbered "24.R" instead of "24.6", so it is an orphan page that the heading-sync script can never renumber; the MBRL supplement still attributes DPO/GRPO/Agentic RL to Chapters 8–10 while the book itself has "9.3 Model-Based RL"; its model-free-vs-model-based code block cannot run (0-dim `torch.cat`, and a `state_dim+2` target against a `state_dim+1` model); the VLA page still calls PPO's output deterministic, contradicting its own Gaussian-policy section; the VADER truncated-backprop gloss cuts the wrong end of the chain ($t>K$ instead of $t\le T-K$); and the audio page still contains both a 40×/10× data-multiple slip and a garbled sentence. The chapter-numbering fixes and the loss-sign fixes are the strongest part of the diff; errors 1–6 are the ones that should block the merge.
