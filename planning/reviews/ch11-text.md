## Errors

1. `docs/chapter11_imitation_meta_rl/irl-gail.md` (line ~101, §2.1) — "**Sampling-based soft Q iteration**: approximate with soft Bellman backups (Guided Cost Learning, Finn et al. 2016)" — wrong attribution. _Guided Cost Learning_ ("Guided Cost Learning: Learning to Plan with High-Dimensional Cost Functions", ICML 2016) is by **Aviv Tamar, Shimon Shalah, Tomer Schwartz and Netanel Satt**. Chelsea Finn's 2016/2017 work is MAML (cited correctly elsewhere in this chapter as "Finn et al. 2017") and the soft-Q-for-IL connection; there is no "Finn et al. 2016" GCL paper. This page was the writer's responsibility and the report explicitly claims "Paper attributions checked ... no benchmark numbers or quotes appear in scope", so the attribution was in scope but not checked. — Suggested fix: "(Guided Cost Learning, Tamar et al. 2016)".

2. `docs/chapter11_imitation_meta_rl/irl-gail.md` (GAIL code block, §3.1) — the block header still says `# === 2. Train the policy: use -log D as the reward ===`, but the line below it computes `rewards = -F.logsigmoid(-self.disc(states, actions))`, which is $-\mathrm{logsigmoid}(-l) = \mathrm{softplus}(l) = \log(1+e^{l}) = -\log(1-D)$, i.e. $-\log(1-D)$, **not** $-\log D$. The writer corrected the inner comment but left this one, so the same snippet now states two different rewards; the surrounding prose ("the code and the formula must use the same convention", and later "The `rewards = -log(1-D)` in the code of the previous part uses exactly this signal") contradicts the header comment. — Suggested fix: change the header comment to `# === 2. Train the policy: use -log(1-D) as the reward ===`.

3. `docs/chapter11_imitation_meta_rl/review.md` (title/H1 + `docs/.vitepress/config.mjs`) — the new page is not reachable from the hand-written sidebar, and its section number is not a valid one. `config.mjs` still lists only `11.1`, `11.2`, `11.3` for Chapter 11, so `/chapter11_imitation_meta_rl/review` is orphaned (AGENTS.md: "Every navigable page must be listed there"). The page titles itself "11.R Summary and Exercises", but every other page in the book uses an `N.M` number and `scripts/fix-heading-numbers.mjs` only rewrites headings for sidebar entries matching `text: 'N.M ...'` — so `11.R` will never be renumbered automatically and does not match the book's numbering scheme. (The report hands this to a "coordinator", but as merged the page is broken.) — Suggested fix: add a sidebar entry `{ text: '11.4 Summary and Exercises', link: '/chapter11_imitation_meta_rl/review' }` under Chapter 11 and change the H1/frontmatter title to `# 11.4 Summary and Exercises` (then `npm run fix:headings` keeps it in sync).

4. `docs/chapter11_imitation_meta_rl/meta-rl.md` (§1.2, `maml_meta_update` snippet) — the snippet cannot run: `for _ in range(n_inner_steps):` references `n_inner_steps`, which is neither a parameter of `maml_meta_update(meta_policy, tasks, inner_lr=0.1, outer_lr=0.001)` nor defined anywhere in the snippet (only `inner_lr` is). A reader copying it gets a `NameError` on the first iteration. The same snippet also does `meta_policy.params -= outer_lr * meta_grad / len(tasks)`, an in-place update of a leaf tensor with `requires_grad=True`, which PyTorch rejects with "a leaf Variable that requires grad is being used in an in-place operation". — Suggested fix: add `n_inner_steps=1` (or `n_inner_steps=5`) to the signature and use `meta_policy.params = meta_policy.params - outer_lr * meta_grad / len(tasks)`.

## Doubts

1. `docs/chapter11_imitation_meta_rl/review.md` (Common Pitfalls) — "Always verify $D^* = 0.5$ gives a neutral reward". Under the convention the chapter uses, $D^* = 0.5$ gives $-\log(1-0.5) = 0.6931$ (or $\pm 0.6931$ for the $\log D$ / $-\log D$ variants) — never $0$. What is neutral at $D=0.5$ is the _discriminator_, not the reward value. — Suggested fix: say "gives an equal reward for expert-like and policy-like pairs (the discriminator is indifferent)".

2. `docs/chapter11_imitation_meta_rl/irl-gail.md` §2 and `docs/chapter11_imitation_meta_rl/review.md` (Key Equations, Exercise 4) — the objective is written with an explicit factor $|\mathcal D|$ on the $\log Z$ term, $\mathcal L(\psi) = \sum_{\tau\in\mathcal D}[\sum_t r_\psi] - M\log Z$, so the exact gradient is $\nabla_\psi\mathcal L = M\big(\mathbb E_{\text{expert}}[\cdot] - \mathbb E_{\text{model}}[\cdot]\big)$, while the displayed gradient drops $M$. The update direction is unaffected (positive constant), but Exercise 4's solution even says "Multiplying by $M$ and subtracting gives the stated gradient" and then presents the $M$-free form, which is internally inconsistent. — Suggested fix: either divide the first term by $M$ in the objective, or keep the factor in the gradient and note that it can be dropped.

3. `docs/chapter11_imitation_meta_rl/irl-gail.md` §3.1 (GAIL snippet) — `self.disc` is called with two different signatures in the same class: `self.disc(self.expert_buffer.sample())` (one batch of $(s,a)$ pairs) in the discriminator step versus `self.disc(policy_states, policy_actions)` (two tensors) in the reward step. The same network cannot take both forms. `ones`, `zeros` and `self.disc_optim` are also never defined. — Suggested fix: use one calling convention (e.g. `self.disc(states, actions)` everywhere) and note where `ones`/`zeros` come from.

4. `docs/chapter11_imitation_meta_rl/irl-gail.md` §3.2 (added occupancy paragraph) — the paragraph introduces a second symbol for the same object: "each $p(s,a)$ is a discounted state-action occupancy measure, $\rho_\pi(s,a) = (1-\gamma)\sum_{t\ge 0}\gamma^t\Pr(s_t=s,a_t=a\mid\pi)$", but never states $p(s,a) = \rho_\pi(s,a)$; a reader may take $p$ and $\rho$ to be different quantities. The definition itself is correct (it sums to 1). — Suggested fix: write "$p(s,a) \equiv \rho_\pi(s,a) = \dots$".

5. `docs/chapter11_imitation_meta_rl/meta-rl.md` §2.1 and §1.2 — two very specific claims could not be traced to the cited papers: the AD narrative ("the first episode ends in death with 52 points, by the 50th it has learned to dodge bullets, and by the 200th it clears the game reliably") and the MAML maze example ("one gradient step brings the policy to about 80% performance on either task A or task B"). The MAML paper illustrates the two-initialization argument qualitatively (Figure 1) without an 80% figure, and the AD paper describes the DQN learning process qualitatively. Since the report claims "no benchmark numbers or quotes appear in scope", these are exactly the numbers that should have been checked. — Suggested fix: either cite the specific figure/table, or soften to a qualitative description.

6. `docs/chapter11_imitation_meta_rl/irl-gail.md` §4.1 and `docs/chapter11_imitation_meta_rl/meta-rl.md` §4.4 — "DWBC" is never expanded and I could not pin the acronym to a specific paper; it appears twice as if it were a well-known baseline. — Suggested fix: expand it ("Discriminator Weighted Behavioral Cloning") and give the citation.

7. `docs/chapter11_imitation_meta_rl/meta-rl.md` — mild internal tension remains after the §3.2 rewrite: §1.5 still says the meta-RL idea "directly inspired in-context learning in LLMs", while §3.2 now says the two are "analogous mechanisms applied to different learning signals, not one discovery made twice" and §4.5 says a few-shot prompt "does not necessarily execute a complete RL algorithm". The three statements are defensible separately but sit uncomfortably together. — Suggested fix: qualify §1.5 ("inspired … in the sense that both adapt from a context") so it does not re-assert the equivalence §3.2 retracts.

8. `planning/content-review-notes.md` — the two Chapter 11 items that this branch fixes ("Wasserstein GAIL 'gradient clipping' wording is garbled; the optimal-transport box heading contradicts its body" and "§3.2 says Algorithm Distillation in-context RL and GPT-3 in-context learning are 'almost the same thing' … reads as contradictory") are still unmarked `[ ]` with no note of the fix, although the file itself says "When you fix an item, mark it `[x]` and note the fix" (AGENTS.md repeats this). — Suggested fix: mark both `[x]` and add the one-line fix note.

9. Rounding nits (verified by arithmetic, harmless): `irl-gail.md` §2 says the reward gap becomes "a probability gap of about 149 times" — the exact factor is $e^{5} = 148.41$; `review.md` Exercise 5 says "roughly $90\times$ more reward" — the exact ratio is $0.916291/0.010050 = 91.2$.

## Verdict

The revision is technically strong where it matters most. I re-derived every new equation and found them correct: the Gaussian BC negative log-likelihood ($\|a-\mu\|^2/2\sigma^2 + (d/2)\log 2\pi\sigma^2$) reduces to MSE at fixed $\sigma$; the GAIL occupancy measure $\rho_\pi(s,a)=(1-\gamma)\sum_t\gamma^t\Pr(s_t=s,a_t=a\mid\pi)$ is right and the implicit-reward identity $-\log(1-\sigma(l)) = -\mathrm{logsigmoid}(-l) = \mathrm{softplus}(l)$ checks out numerically (0.1269 / 0.6931 / 2.1269 at $l=-2,0,2$). The two cross-reference fixes are right (SAC is §9.2; Chapter 14 only has §§14.1–14.4, so "see 14.6" was dangling), the JS-divergence retitle matches the box body, the WGAN→WGAN-GP history bullet is correct, and the §3.2 rewrite removes a genuine contradiction without overclaiming. All eight `review.md` exercises are correct — I recomputed every number in them (BC losses 0.3567/0.0513, mean 0.3851; $0.98^{50}=0.3642$; $D^*$ 0.6/0.01 with rewards 0.9163/0.0101; the MAML hand computation 2.56 vs 5.12; the Gaussian BC mean 0 and variance 1) and every solution matches. The problems are concentrated in the periphery rather than the mathematics: one paper misattribution the report claims to have checked (GCL is Tamar et al. 2016, not "Finn et al. 2016"), a leftover contradictory sign comment in the GAIL snippet that the writer edited one line away from, a new page that is orphaned from the sidebar and numbered "11.R" in a scheme the heading-fixer cannot manage, and a non-runnable MAML snippet. None of these undermine the chapter's technical content, but the misattribution and the orphaned review page should be fixed before merge.
